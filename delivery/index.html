Installation notes

无需配置开发环境

目标：Windows 10 22H2 或 Windows 11 x64，.NET Framework 4.8+ 与 Evergreen WebView2。按当前用户安装，从开始菜单启动。已内置 Python、Agent、Git 和 FFmpeg。AI 功能需要自行配置模型；导出时保持应用运行。预览安装包没有 Authenticode 签名。
