# A1 双模式：简洁模式 / 进阶模式（方案，尚未实现）

状态：**方案已确定，代码未实现。** 本文件记录用户确认的方向，供后续开发者或用户自己在新界面中继续。

## 用户确认的决定

1. 两种模式：**简洁模式** 与 **进阶模式**。
2. **简洁模式**：参考即梦、TapNow 的路线，用户输入一句话即可直接生成视频，不需要精细调参。
3. **进阶模式**：保留现在的完整工具流（画布节点、生成面板、Agent 工具链、时间线等）。
4. 模式可以在 **设置** 中随时切换。

## 与上游的关系

上游 ThinkFlowLab/OpenDirector 的 RFC #386 与 WIP PR #380 定义了 **纯净模式**（以 Agent 为中心的对话）与 **画布模式**（对话 1/3、画布 2/3，记住偏好，切换时保留状态）。

用户提出的两种模式**不是同一个概念**：
- 上游的切换是"对话在前还是画布在前"。
- 用户的切换是"一句话出片的简化路线"与"完整工具流"。

因此不宜直接沿用上游的命名。若与上游合作，应说明这一差异，并确认是否合并为同一套开关或保持两条路线。

## 简洁模式的范围（草案）

- 单一输入框：一句话描述 + 可选参考图（仅上传，不做 `@` 引用）。
- 默认参数由系统选择（模型、时长、画幅），用户可以看到但不必修改。
- 生成完成后直接显示结果卡片，可一键转入进阶模式继续编辑（同一工程）。
- 失败状态与 B1 相同：给出明确的终止提示，不无限"思考"。

## 进阶模式的范围

- 保持现有实现，不做功能删减。
- 切换到进阶模式时，保留简洁模式中已生成的工程与素材。

## 切换与持久化

- 入口：设置 → 模式（"简洁" / "进阶"）。
- 偏好保存在本地设置中，下次启动沿用。
- 切换不得丢失未保存的内容，也不得打断正在运行的生成任务。

## 依赖

- **B2（#321，切换项目后 Agent 写入失败）**：切换模式与切换项目都会改变编辑会话的归属。在 B2 修复之前，切换模式后 Agent 可能无法写入。B2 应先于 A1 完成。
- **会话租约释放**（B1 验证中发现）：窗口关闭时未释放租约，会导致其它窗口打不开工程。同样需要在 B2 的租约设计中解决。

## 验收标准（草案）

- [ ] 设置中可以在两种模式之间切换，偏好在重启后保持。
- [ ] 简洁模式：输入一句话后直接得到视频结果，无需进入节点画布。
- [ ] 进阶模式：现有功能全部可用，回归测试通过。
- [ ] 切换模式时，运行中的生成任务不中断，已生成内容不丢失。
- [ ] 在 Windows 真机上录制两种模式的完整演示视频（mp4）。
