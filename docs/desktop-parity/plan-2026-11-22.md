## 0. 目标与边界

- **总目标**：在 omni（多模态视频创作）领域做出 opencode 之于编码那样的开源 harness 地位。Windows 端的体验 **≥ 原项目网页版**，并且 Windows 原生感更强。
- **本轮只做 Windows 端**（用户约束 1）。共享层修复（Fit all、节点重叠、失败卡出口等）整理后回馈上游。
- **验收纪律**（用户约束 4 与 7）：每批改进 = 代码 + 补丁 + 静态守卫 → 真浏览器全量旅程录屏（mp4）→ windows-2022 装机冒烟（`OD_VERIFY_RENDER=1`）→ progress.md 逐项更新 → 向用户交付 mp4。

**关于「真机」的诚实说明**：沙箱是 Linux，没有 Windows 桌面。本轮的「真机」证据仍是两轨：①沙箱真实 Chromium 操作的全量旅程录屏；②GitHub `windows-2022` runner 上真实 WebView2 原生窗口的装机冒烟与录像（推送分支即触发 `windows.yml`，产物进 `evidence/windows-native`）。两轨的结论分别陈述，不合并宣称。

## 2. 与 PR #397 的对照（借鉴结论）

PR #397（上游，Electron 壳 + 本地 Python Host）的可借鉴点，以及我们的取舍（详见 DESKTOP-PARITY-REVIEW.md）：

- **借鉴并已采用**：导出信号（`data-od-exporting`，我们取「信号」弃其「桥」，桥作兼容层保留）；双语默认名与切换不覆盖用户命名；侧边栏可折叠；示例画布经本地 Host 下载并显示进度；`window` 控件平台化；桌面架构文档结构。
- **我们已有而 #397 没有**：WebView2 原生宿主（无 Electron 体积）、Sigstore 验证的自动更新、CLI 与 GUI 共用租约、窗口状态记忆（C3）、失败卡三出口与 Escape、多窗口自愈等待、Agent 独立租约（B2）。
- **#397 尚未覆盖、我们应补的**：Windows 安装/卸载/升级的真机验收（我们已有 CI 证据）；其 Mac 侧工作不在本轮范围。

结论：不切换到 Electron；把 #397 的 UX 细节（侧边栏、双语命名、示例下载进度）按我们的 WebView2 架构等价实现，并在桌面冒烟里覆盖。

## 3. 竞品滚动研究（本轮新增）

- **TapNow**（2026）：节点画布编排多家文本/图像/音频/视频模型；Agent 定位为「AI 执行导演」，承诺跨镜头角色/光影/风格一致性、下一镜预测；生成前显示成本估算；Windows 与 Apple silicon 桌面端；本地授权文件夹内的 Desktop Agent；模板与 Remix 社区。来源：[toolcenter](https://www.toolcenter.ai/en/articles/tapnow-ai-review-2026)、[aidown](https://www.aidown.com.cn/en/software/tapnow/)。
- **即梦**（2025–2026）：无限画布（无限空间、Agent 共创、多会话并行、图片/视频混合编辑）；画布内素材「工单模式」一键调用；Agent 增加「灵感搜索 / 创意设计」两种对话模式；视频片段局部修改、仅尾帧模式。来源：[新浪财经](https://finance.sina.com.cn/roll/2025-12-17/doc-inhccnef7065454.shtml?froms=ggmp)、[CSDN 解析](https://blog.csdn.net/Ashtar_katay/article/details/154498361)。

由此新增到候选池（编号 N 系列，写入 backlog）：

- **N1 生成前成本与时长估算**（TapNow）：Build 前显示预计消耗，避免付费误触。
- **N2 素材托盘 / 工单**（即梦）：画布外常驻素材栏，拖入即用，与 A6 合并。
- **N3 Agent 灵感 / 创意两种对话意图**（即梦）：映射到简洁模式的入口提示，不改模型。
- **N4 下一镜 / 分镜续写预览**（TapNow）：依赖现有 Agent，列为 P5 之后。
- **N5 授权文件夹的只读资产导入**（TapNow Desktop Agent）：与 B8 权限策略一起设计，Windows 上用系统文件选择器授权。

## 5. 风险

- **B2/租约是数据安全关键路径**：任何改动须配并发测试，并保留 `tests/test_transport.py` 与 `test_run_lease_*` 全绿。
- **补丁链脆弱**：每次改动 `patches/` 后，从 `git show` 移植头注释，并跑 `scripts/package.py` 的四个集成点检查。
- **沙箱缺 ffmpeg/Chromium**：需用 PyPI（`imageio-ffmpeg`）与 npm（`playwright-core` + 浏览器包）补齐；若二进制无法获取，录屏环节会阻塞，需在进展中如实标注。
- **Windows 真机不在沙箱**：C9 等运行时分支依赖专门的验证方式，无法在 Linux 证明。
